# USDT 來源追查（TRC20）

貼上你的 USDT-TRC20 收款地址，往上追付款人、付款人的付款人，逐一比對 Tether 凍結黑名單。

**線上版：** <https://sentinelbotsaas-hub.github.io/usdt-trace/>

## 為什麼需要

收到「打折 U」、柬埔寨／緬甸那邊收的帳、幫人代收代轉的錢，入金交易所後可能被執法單位要求凍結，而且交易所自己解不開。最好在收款當下就知道這筆錢的上游乾不乾淨。

## 安全

- **不連接錢包、不要求簽名或授權、不碰助記詞。**只讀鏈上公開資料。
- 整個工具是一個 `index.html`，在你的瀏覽器裡直接打 [TronGrid](https://www.trongrid.io/) 公開 API，沒有後端，不收集任何資料。
- 任何要你「連錢包檢查 U 乾不乾淨」的網站都是盜幣詐騙。

## 它檢查什麼

| 訊號 | 說明 |
|---|---|
| 直接黑名單 | 付款地址本身被 Tether 凍結（呼叫 USDT 合約 `isBlackListed`） |
| 上游第 N 層命中 | 付款人的資金來源裡有黑名單地址 |
| 新錢包 | 付款時錢包建立不到 30 天，常見於一次性過水錢包 |
| 交易所／OTC 樞紐 | 進出合計 1,000 筆以上的地址（含只出不進的出款熱錢包），追到這裡就停（再往上每條路都連到所有人） |

預設追 3 層：第 1 層全部付款人；第 2 層起每個地址只追金額前幾大的來源。

**看時間先後**：每一層只算「付款給下一層之前」進來的錢（TronGrid `max_timestamp`）。付款之後對方才收到的黑錢，不可能流進你那筆，不會誤報。

## 它不能做什麼

- 看不到成交價格，「打折」本身無法從鏈上判斷。
- Tether 黑名單只涵蓋 Tether 自己凍結的地址；執法機關要求交易所凍結的帳戶不一定在上面。**乾淨不代表一定安全，命中則幾乎確定有問題。**
- 只查 USDT-TRC20。
- 不標示交易所名稱（需要付費標籤 API）。

## 自己跑

下載 `index.html` 用瀏覽器打開即可。免費 TronGrid 有頻率限制，查得多可以到 TronGrid 免費申請 API Key 填進去。
